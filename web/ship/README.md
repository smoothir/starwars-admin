# Illustrations des classes de vaisseaux

Les images associées aux catégories de vaisseaux sont téléversées depuis la page **Factions** du site administrateur.

- Formats acceptés : PNG, JPEG, WEBP et GIF.
- Taille maximale : 4 Mo par image.
- Les fichiers sont enregistrés dans ce dossier (`web/ship`).
- Le nom de fichier est généré par le serveur à partir de l'identifiant interne de la catégorie ; il ne faut pas saisir de chemin de fichier.
- Une image par catégorie est conservée. Un nouvel envoi remplace l'ancienne image de cette catégorie.

Les sauvegardes complètes comprennent également ces images et les rétablissent lors d'une restauration.
